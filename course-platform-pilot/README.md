# Mr Flynn IB course platform pilot

This is an isolated, local-only prototype of the future student course experience. It does not change or deploy the public MrFlynnIB website.

## Included

- AA SL, AA HL, AI SL and AI HL course experiences
- All five syllabus topics for every course
- 442 verified, student-facing Bunny Stream videos across 20 organised collections
- 640 Teachable-aligned lesson placements across the four courses
- Shared SL-and-HL foundations plus clearly labelled HL extensions
- Real Bunny Stream playback, topic navigation and whole-course search
- Two-question lesson practice for 355 of the 442 unique videos, covering 505 of the 640 course placements with exact existing question-bank records and mark schemes
- A top-level past-paper solutions hub with course, session, paper and question navigation
- 1,207 verified Teachable-to-Bunny past-paper solution placements across the four IB courses
- Lesson completion and resume state stored only in the browser
- Course and topic progress views
- Responsive desktop and mobile layouts
- Prototype single-login screen

## Not yet production functionality

- Real authentication or password storage
- Payments and access expiry
- Secure signed Bunny playback tokens
- Practice for 87 fine-grained lessons where the existing bank does not yet provide two sufficiently precise short matches
- Persistent server-side progress
- Email or account administration

Serve the repository root locally, then open `/course-platform-pilot/dist/`.

`dist/library-data.js` is a static, non-secret snapshot of the Bunny library metadata used by the prototype. Refresh it with `generate-library-data.mjs`, passing the verified Bunny snapshot and Teachable catalogue paths. The generator includes only ready AA/AI course collections, maps the exact Teachable lesson catalogue, removes exact duplicate records, prefers combined and Teachable-edit versions, and keeps deliberately suppressed videos out of the student preview.

`dist/past-paper-data.js` is generated by `generate-past-paper-data.mjs` from the verified Teachable-to-live-Bunny reconciliation. It includes only exact verified mappings for AA HL, AA SL, AI HL and AI SL, groups them by exam session and paper, and writes no Bunny API key to the project.

`dist/practice-data.js` is generated by `scripts/generate-practice-data.mjs` from the verified IB question bank and the exact lesson catalogue. It preserves the approved 12-lesson pilot selections, assigns a canonical course bank to shared SL-and-HL videos, excludes off-syllabus and provisional questions, strongly prefers questions of eight marks or fewer, and leaves weak or ambiguous lesson matches unfilled. AA question cards display **Paper 1 · Non-calculator** or **Paper 2 · Calculator** using the course-specific paper mapping in the bank. `practice-audit.csv` records every mapping, mark total, paper/calculator classification and honest review gap.
